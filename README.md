# Netflix-Power-BI-Dashboard
Power BI dashboard analyzing Netflix titles, genres, ratings, and trends.


## Key Insights
- 🎥 Movies dominate (~70%) vs TV Shows (~30%)
- 🌍 Top producing countries: US, India, UK
- 📈 Surge in releases after 2000, peaking 2018–2020
- 🎭 Genres led by Drama, Documentary, Comedy

## Files
- `Netflix.pbix` → Power BI dashboard file
- `netflix_titles.csv` → Dataset
- `dashboard.png` → Screenshot of dashboard

## How to Use
1. Download the `.pbix` file.
2. Open in Power BI Desktop.
3. Explore visuals and slicers interactively.

## Skills Demonstrated
- Data cleaning with Power Query
- DAX measures for KPIs
- Dashboard design and storytelling
